# Villa SDK for Lovable

Passkey auth for AI-generated apps. Zero config, one component.

## Install

```bash
npm install @rockfridrich/villa-sdk @rockfridrich/villa-sdk-react
```

## Basic Usage (VillaButton does everything)

```tsx
import { VillaButton } from '@rockfridrich/villa-sdk-react'

function App() {
  return (
    <header>
      <VillaButton />
    </header>
  )
}
```

That's it. VillaButton handles:
- Sign in popup (passkey auth)
- Profile dropdown when logged in (avatar, nickname)
- Copy wallet address
- Settings (edit profile)
- Sign out

## Access User Data

```tsx
import { useVilla } from '@rockfridrich/villa-sdk-react'

function Profile() {
  const { user, isLoading } = useVilla()
  
  if (isLoading) return <div>Loading...</div>
  if (!user) return <div>Not logged in</div>
  
  return (
    <div>
      <img src={user.avatar} alt="" />
      <p>@{user.nickname}</p>
      <p>{user.address}</p>
    </div>
  )
}
```

## User Object

```typescript
{
  address: "0x1234...5678",    // Ethereum wallet address
  nickname: "SunnyBaker",      // User's display name
  avatar: "https://...",       // Avatar image URL
  createdAt: "2026-01-23..."   // Registration date (optional)
}
```

## Custom Integration

If you need more control:

```tsx
import { useVilla, VillaProfile } from '@rockfridrich/villa-sdk-react'
import { villa } from '@rockfridrich/villa-sdk'

function CustomAuth() {
  const { user, signIn, signOut } = useVilla()
  
  if (!user) {
    return (
      <button onClick={() => signIn()}>
        Sign In
      </button>
    )
  }
  
  return (
    <VillaProfile 
      user={user}
      onSettings={() => villa.settings()}
      onSignOut={signOut}
    />
  )
}
```

## Settings Popup

Let users edit their profile:

```tsx
import { villa } from '@rockfridrich/villa-sdk'

async function openSettings() {
  const result = await villa.settings()
  
  if (result.loggedOut) {
    // User signed out
  } else if (result.nickname) {
    // Profile was updated
  }
}
```

## Component Reference

### VillaButton
All-in-one auth button. Shows sign-in when logged out, profile dropdown when logged in.

```tsx
<VillaButton 
  onSignIn={(user) => console.log('Welcome', user.nickname)}
  onSignOut={() => console.log('Goodbye')}
  showProfileDropdown={true}  // default: true
/>
```

### VillaProfile
Profile dropdown component with copy wallet, settings, sign out.

```tsx
<VillaProfile
  user={user}
  onSettings={() => villa.settings()}
  onSignOut={() => villa.signOut()}
/>
```

### useVilla Hook
Access auth state anywhere.

```tsx
const { 
  user,           // Current user or null
  signIn,         // () => Promise<VillaUser>
  signOut,        // () => void
  isLoading,      // boolean
  isAuthenticated // boolean
} = useVilla()
```

## Upgrade from v0.0.x

If you have an older Villa integration:

```tsx
// OLD (v0.0.x)
import { VillaAuth } from '@rockfridrich/villa-sdk-react'
<VillaAuth onComplete={(result) => {...}} />

// NEW (v0.1.x) - simpler!
import { VillaButton } from '@rockfridrich/villa-sdk-react'
<VillaButton />
```

Key changes:
- VillaButton replaces VillaAuth for most use cases
- Built-in profile dropdown (no custom UI needed)
- Settings popup for profile editing
- Copy wallet address with one click
