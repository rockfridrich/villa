# Villa SDK Integration Guide

> This file contains everything needed to integrate Villa authentication.
> No external references required - works offline.

## Install

```bash
npm install @rockfridrich/villa-sdk-react
```

## React (Recommended)

```tsx
import { VillaAuth } from '@rockfridrich/villa-sdk-react'

function App() {
  const [user, setUser] = useState(null)

  if (!user) {
    return (
      <VillaAuth
        onComplete={(result) => {
          if (result.success) setUser(result.identity)
        }}
      />
    )
  }

  return <h1>Welcome, @{user.nickname}!</h1>
}
```

## Vanilla JavaScript

```typescript
import { villa } from '@rockfridrich/villa-sdk'

// Sign in
const result = await villa.signIn()
if (result.success) {
  console.log(result.identity.address)   // 0x...
  console.log(result.identity.nickname)  // "alice"
}

// Check auth
if (villa.user) {
  console.log('Logged in as', villa.user.nickname)
}

// Sign out
villa.signOut()
```

## Types

```typescript
interface Identity {
  address: `0x${string}`
  nickname: string
  avatar?: {
    style: 'adventurer' | 'avataaars' | 'bottts' | 'thumbs'
    seed: string
  }
}

type SignInResult =
  | { success: true; identity: Identity }
  | { success: false; error: string; code: 'CANCELLED' | 'TIMEOUT' | 'NETWORK_ERROR' }
```

## React Hooks

```typescript
import { useVilla } from '@rockfridrich/villa-sdk-react'

function MyComponent() {
  const { user, signIn, signOut, isLoading } = useVilla()

  if (isLoading) return <p>Loading...</p>
  if (!user) return <button onClick={signIn}>Sign In</button>
  return <button onClick={signOut}>Sign Out @{user.nickname}</button>
}
```

## Next.js App Router

```tsx
// app/layout.tsx
import { VillaProvider } from '@rockfridrich/villa-sdk-react'

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        <VillaProvider>{children}</VillaProvider>
      </body>
    </html>
  )
}

// app/page.tsx
'use client'
import { useVilla, VillaAuth } from '@rockfridrich/villa-sdk-react'

export default function Home() {
  const { user } = useVilla()
  if (!user) return <VillaAuth onComplete={() => {}} />
  return <h1>Welcome @{user.nickname}!</h1>
}
```

## Error Handling

```typescript
const result = await villa.signIn()

if (!result.success) {
  switch (result.code) {
    case 'CANCELLED':
      // User closed modal - this is normal
      break
    case 'TIMEOUT':
      alert('Authentication timed out')
      break
    case 'NETWORK_ERROR':
      alert('Network error - check connection')
      break
  }
}
```

## Advanced: Villa Class

```typescript
import { Villa } from '@rockfridrich/villa-sdk'

const client = new Villa({
  appId: 'my-app',
  network: 'base',  // or 'base-sepolia' for testnet
})

const result = await client.signIn({
  scopes: ['profile'],
  timeout: 5 * 60 * 1000,
})

// ENS resolution
const address = await client.resolveEns('alice.villa.cash')
const name = await client.reverseEns('0x...')
```

## What Villa Returns

After authentication:
- `address`: Ethereum address derived from passkey
- `nickname`: User's chosen name (resolves via ENS)
- `avatar`: Optional avatar configuration

## Security

- Passkeys never leave the device (WebAuthn)
- Villa never sees private keys
- Sessions stored locally (7-day TTL)
