# Task Tracking

This directory contains active task lists for work in progress.

## Task Format

Tasks are tracked in markdown files with the following format:

```markdown
# Task: [Brief Description]

Status: pending | in_progress | completed | blocked
Priority: high | medium | low
Spec: link to spec if applicable
Assigned: @agent or human

## Context

What triggered this task.

## Acceptance Criteria

- [ ] Criterion 1
- [ ] Criterion 2

## Progress Log

- [timestamp] Update
```

## Task Lifecycle

1. Created from spec or direct request
2. Assigned to agent or human
3. Tracked via progress log
4. Completed when all criteria met
5. Archived after verification
